# USTC 评课社区助手 (USTC Icourse Helper)

为 [USTC 评课社区](https://icourse.club)（icourse.club）增强的油猴脚本。基于 [PRO 的 USTC Helper](https://greasyfork.org/zh-CN/scripts/453530-ustc-helper)（GPL-3.0）的 icourse 模块提取并改进，**无任何外部依赖**。

## 功能

- **悬浮资料面板**：页面右边缘的「资料」按钮显示资料总数，点击展开；首次使用仅提示入口位置，不自动展开或定时收起。桌面使用较宽面板，窄屏自动适配；支持 Esc 收起和键盘操作
- **分类与搜索**：按全部、文件、链接切换，可搜索文件名、链接或老师；本页暂无资料时仍保留入口，方便搜集其他老师的资料
- **文件列表**：自动收集课程点评区的所有附件（讲义、试卷、复习提纲等），点击直接下载（自动补全文件名）；名称最多显示两行，文件类型和来源单独显示
- **链接列表**：自动收集点评区的所有外部链接，新标签页打开
- **定位**：本页条目带「定位」按钮，滚动到原点评并短暂高亮；桌面保留面板方便连续浏览，窄屏先收起面板避免遮挡；尊重系统的减少动态效果设置
- **搜集其他老师的同课程资料**：面板底部固定显示搜集按钮、进度和结果，汇总侧边栏「其他老师的课」中的附件与链接，来源老师可点击跳转。成功获取的页面当日缓存于 localStorage；部分失败时可以单独重试，成功结果不会重复添加
- **未登录也能用**：评课社区对未登录用户隐藏附件直链，但保留文件名——脚本会列出这些附件并提示登录后下载；文件本身其实是公开可下载的，登录后自动变为直链

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击安装：[Greasyfork](https://greasyfork.org/zh-CN/scripts/600738-ustc-icourse-helper)（推荐，自动更新）或 [USTC-Icourse-Helper.user.js](https://github.com/quantai1314/ustc-icourse-helper/raw/main/USTC-Icourse-Helper.user.js)

## 说明

- 仅在课程详情页（`/course/<id>/`）生效
- 纯本地运行，不与任何第三方通信；抓取其他老师课程页仅在点击按钮后发生
- 相比原模块的改进：改为悬浮面板常驻、过滤了无效的 `#` 锚点链接和登录弹窗链接、新增未登录用户的附件识别、新增跨老师资料搜集与同页去重
